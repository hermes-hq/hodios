# Hodios brand

*Hodios* is Hermes as guide of roads and travellers; his roadside waymarker was the *herm*. The mark is a capital **H** drawn as circuit traces whose crossbar runs on past the post as a direction sign, with a milestone on the road. It is a sibling of the [Hermes IDE](https://hermes-ide.com) logo: same neon trace style, same cyan-to-violet glow.

These assets are CC0-1.0, like the library content. Use them freely; please keep the mark recognisable.

## Files

| File | Use |
|---|---|
| `hodios-mark.svg`, `hodios-mark-{512,256,64}.png` | The logo mark on a transparent background. Use at 48 px and up. |
| `hodios-mark-small.svg`, `hodios-mark-small-{32,16}.png` | Simplified mark for 16 to 32 px: solid strokes, no nodes. |
| `hodios-icon.svg`, `hodios-icon-{1024,512,256}.png` | App icon: glowing mark on the dark rounded square. Avatars, app stores, docs sites. |
| `hodios-icon-small.svg`, `favicon.ico` | Favicon (16, 32, 48 px) on the dark square, so it reads on light and dark tabs. |
| `banner-dark.png`, `banner-light.png` | README banner, 1280×400. Swap with `<picture>` and `prefers-color-scheme`. |
| `social-preview.png` | GitHub social preview, 1280×640. Upload in **Settings → General → Social preview**. |

## Colors

| Role | Hex |
|---|---|
| Trace gradient, top | `#38D6F5` (cyan) |
| Trace gradient, bottom | `#9B5CF6` (violet) |
| Glow gradient on dark | `#4FDDF8` → `#A874FA` |
| Icon background | `#100F24` → `#060512` |
| Text on dark | `#F5F3FF` |
| Text on light | `#13122B` |
| Accent on light (links, eyebrow) | `#0E7490` / `#7C3AED` |

The gradient always runs top to bottom, cyan to violet.

## Type

The wordmark and tagline are set in [Outfit](https://fonts.google.com/specimen/Outfit) (SIL OFL): SemiBold for "Hodios", Regular for the tagline. Text is never part of the generated artwork; it is set as its own layer.

## Usage

- Use the mark on dark backgrounds where possible. On light backgrounds, use it as is or use the app icon.
- Below 48 px use the simplified mark or the favicon.
- Keep clear space around the mark of at least the width of one node ring.
- Do not recolor, rotate, outline or stretch the mark, and do not add text inside the icon.
