# Step 5: Routine

Keep it from drifting back.

1. Write a weekly ten-minute sweep: empty the inbox, file or link new notes, fix new tags against the tag list.
2. Write a monthly check: unused tags, new duplicates, stale drafts to archive.
3. Write a yearly check: archive finished projects, test a backup restore, review the folder list.
4. Put the rules from step 2 on one page the person can keep at the top of the collection.
