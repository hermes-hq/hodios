# Step 2: Target structure

Design where things will live, kept as small as possible.

1. Propose at most about six top-level folders for the stated purpose, plus an Archive.
2. Write tag rules: what a tag is for, when to use a link or a property instead, and a short tag list grouped as type, status and topic.
3. Map every existing folder and tag to its new place, a link, a property, or "drop".
4. Set note title rules for the main note types.

Stop and ask the person to approve the structure and the mapping before anything is moved.
