# Step 5: Plan a cheap test

Learn whether the idea works before investing in it.

1. Design the cheapest test of the riskiest assumption that can run within two weeks: a conversation with a set number of the people it is for, a mock-up, a one-off trial, a sign-up page or a manual version.
2. Set the success threshold before the test runs, and what happens if it is met, missed or unclear.
3. List what the test needs: people, materials, permissions to check, and who does what by when.
4. Close with a one-paragraph summary of the journey: the question, the idea, why it was chosen and the test.

Remind the person they can rerun step 2 with different techniques if the test fails.
