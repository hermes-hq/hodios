# Step 3: Devices and router

Make every device locked, updated and findable.

1. Every phone, tablet and computer: automatic updates on, a screen lock, device finding on, and a backup that works.
2. Remove apps nobody uses and review sensitive app permissions (location, microphone, camera).
3. Router: change the default admin password, update firmware, use current Wi-Fi encryption, turn off WPS and remote management if unused, and put smart TVs, cameras and guests on a guest network if the router supports it.
4. Cameras and smart devices: unique passwords, two-factor on their accounts, remove old shared users.
5. Note any device that no longer gets updates and plan to replace or limit it.

Stop and ask the person to report what was changed before moving to privacy.
