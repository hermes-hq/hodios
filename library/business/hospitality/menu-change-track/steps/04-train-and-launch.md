# Step 4: Train and launch

1. Launch timeline working back from the launch date: supplier orders, print or digital menu updates, online listings and delivery platforms, allergen matrix updated, stock of old items run down.
2. Kitchen training: a run-through for each station using the spec sheets, and a check that every cook can produce each dish to spec.
3. Front of house briefing: a staff tasting, how to describe each dish, pairing or upsell lines that are honest, and how to answer allergy questions using the matrix only.
4. Launch week: a soft start if possible, what the manager watches each service (ticket times, returns, comments) and how to fix issues fast.
5. A one-page checklist for the day before launch.

Sections: Launch timeline, Kitchen training, Front of house briefing, Launch week, Day-before checklist, Open questions.

Stop and wait for approval.
