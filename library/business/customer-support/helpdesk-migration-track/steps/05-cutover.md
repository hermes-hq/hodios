# Step 5: Cut over and check

1. Choose the cutover time (lowest volume, not peak season), and write the runbook in order: freeze changes in the old tool, final export of open tickets, switch forwarding, widgets and phone routing, verify each channel with a test contact, and confirm to the team.
2. Plan the old tool after cutover: read-only access for a set period, replies to late old-thread messages, and when it can be closed under the data rules.
3. Rollback: the trigger and the steps to point channels back.
4. Checks for the first two weeks: unassigned or misrouted tickets, response times against target, missing integration data, agent questions, and customer complaints about lost conversations.

Sections: Runbook, Old tool after cutover, Rollback, First two weeks, Open questions.
