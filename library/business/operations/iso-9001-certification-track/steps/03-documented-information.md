# Step 3: Documented information and records

Decide the minimum documents and records, then draft them.

1. List what the standard explicitly expects to be documented or retained (scope, policy, objectives, evidence of competence, monitoring and calibration, supplier evaluation, nonconformities and corrective actions, internal audit and management review results, and others in clauses 4 to 10), each with the clause. Mark any item you are unsure the standard requires as `[CHECK in the standard]` rather than asserting it.
2. For each core process decide: a short procedure, a flowchart, a form, or no document because a record is enough. Default to the lightest option that keeps the work consistent.
3. Set up control of documents and records: numbering, version, approver, where kept, retention.
4. Draft the items the owner picks first. Put names, values and limits as `[CONFIRM]`.
5. Say which records need to start now so evidence exists by audit day.

Stop for approval.
