# Step 4: Agree the number

1. Line up the adjusted forecast with other views (finance top-down, sales bottom-up, the target) at the same level and units; show each gap.
2. Explain the gaps by cause, reconcile the levels so they add up, and list the disagreements that remain as explicit decisions with owners.
3. Translate the agreed forecast into planning numbers for the decisions it feeds (for example a higher percentile for stock or capacity when shortages cost more).

Sections: Views compared, Gaps and causes, Reconciled forecast, Decisions needed, Planning numbers. Stop for approval.
