# Step 3: Adjustments

1. List the known events and inputs from stakeholders: promotions, price changes, launches, lost or won customers, capacity limits, moving holidays.
2. For each, check whether the baseline already captures it; adjust only for what is new, sized from past analogues, including dips before and after promotions and cannibalisation.
3. Push back on adjustments with no evidence or within normal error, and on any adjustment that is really a target.
4. Write the adjustment log: event, periods, size, evidence, owner.

Sections: Inputs received, Already in baseline?, Adjustments applied, Adjustments declined and why, Adjusted forecast, Adjustment log. Stop for approval.
