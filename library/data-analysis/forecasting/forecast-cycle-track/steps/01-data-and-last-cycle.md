# Step 1: Data and last cycle

1. Load the new actuals and check them: missing periods, late data, stock-outs or outages that censor demand, definition or hierarchy changes, one-off events.
2. Score last cycle: compare the forecast made at the decision lag with the actuals using WAPE and bias (signed error), by item group. If statistical and final versions exist, compute forecast value added for the overrides.
3. Note what last cycle got wrong and why (event, process, data, noise), and the lessons to apply this cycle.
