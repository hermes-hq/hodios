# Step 1: Reference breakdown

Break the character's outfit into buildable components.

Character: {{character}}
Deadline: {{deadline}}
Experience: {{skill}}

1. If the character or outfit version is ambiguous (a character with several outfits, an unclear source), ask which version and stop. If reference images are attached, describe what you see; if none, list the views the maker should collect (front, back, side, close-ups of details, official art versus in-game models) and work from the best-known version, marked as an assumption.
2. List every component, head to toe: wig and hair, makeup or prosthetics, garments by layer, armour and hard parts, accessories, props, footwear.
3. For each component give: the likely construction category (sew, modify a bought item, EVA foam, thermoplastic, 3D print, buy), a difficulty for a {{skill}} maker, and whether it is essential to read as the character or optional detail.
4. Flag the hard parts: anything with no clear reference, structural pieces, lights or electronics, large props, and anything that limits vision, movement, sitting or using the toilet.
5. Suggest a scope that fits the time until {{deadline}}: which components to make, which to buy or modify, and what to leave for a later version.

Stop and wait for the maker to approve or change the component list and scope.
