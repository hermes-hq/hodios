# Step 5: First boot, drivers and tuning

1. First power on: with the side panel off, nothing loose in the case and fans clear of cables, plug in and switch on. If you see sparks, smell burning or hear a pop, switch off at the wall at once and do not retry until the cause is found. Then enter the firmware setup, confirm the processor, memory amount and drives are detected, and check temperatures at idle.
2. If it does not boot: read the board's debug lights or beeps per the manual, reseat memory, check power cables and the display cable.
3. Install the operating system from official media, then chipset and graphics drivers from the manufacturers' sites.
4. Enable the memory's rated speed profile in firmware, then test stability with a demanding game for an hour while watching temperatures.
5. Set the monitor's refresh rate in the operating system, then tune each game's settings for the target from step 1.
6. Finish with a checklist: backups, firmware update plan, warranty registration, and keeping boxes for the return window.
