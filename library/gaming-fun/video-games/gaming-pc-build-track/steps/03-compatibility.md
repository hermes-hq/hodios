# Step 3: Compatibility check

Check the builder's exact models:
1. Processor socket matches the motherboard; the motherboard may need a firmware update for this processor (check the maker's support list).
2. Memory type matches the board; two sticks in the right slots for dual channel.
3. Graphics card length and thickness fit the case; cooler height fits the case.
4. Power supply wattage covers the maker's recommendation for the card, with the right connectors.
5. Storage connections and slots are available.
6. Motherboard size fits the case.

Present a table: Check | Result (pass, fail or check) | How to confirm. Flag any fail with a swap.

Stop for approval before ordering or building.
