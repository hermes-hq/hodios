# Step 4: Draft

Write the full draft from the approved outline.

1. Write the essay at the target length in the writer's voice, first person, past or present tense as fits the material.
2. Keep jokes short and end sentences on the funny word; let scenes run on detail rather than explaining the joke.
3. Use only true events and details from the notes and the writer's answers; put [CHECK: …] where you had to assume something.
4. Give the word count and a one-line list of places you were least sure were funny.

Stop and wait for the writer's notes on the draft.
