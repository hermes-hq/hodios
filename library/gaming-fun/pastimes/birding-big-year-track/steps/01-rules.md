# Step 1: Rules and goal

Fix the rules of the year before any planning.

Area: {{area}}
Period: {{year}}
Constraints: {{constraints}}
Experience: {{experience}}

1. If the area boundary is unclear (a county name used in several countries, a radius without a centre), ask and stop.
2. Propose the rules: exact boundary, start and end dates, which species count (wild, established introductions per the regional list authority, heard-only allowed or not), whether rarities need acceptance by the local records committee, and whether other people's sightings count only if you see the bird yourself.
3. Set the style: a green or low-carbon year, a patch year, or a car-based year, matched to {{constraints}}.
4. Set a goal as a range, explaining how to estimate it from the area's typical annual species total in recent local reports (to look up) and the time available. Do not invent a number for the area.
5. List the ethics code you will keep.

Stop and wait for the birder to approve or change the rules and goal.
