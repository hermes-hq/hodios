# Step 5: Run the night

1. A run sheet from setup to pack-down: arrival, table setup, sound check, each round, marking windows, break, final scores, prizes.
2. A dispute rule: the host's answer stands unless a team shows the question allowed another answer; rulings apply to every team equally.
3. What to do if behind time: drop a round or shorten one, never rush the final.
4. A short after-note: thank-you message wording, and a list of questions that caused disputes to fix next time.
