# Step 4: Make the materials

1. Team answer sheets: one per round, team name box, numbered lines, joker box if used.
2. Picture handout layout if there is one.
3. Host script: welcome, rules read in under a minute, each question as read aloud, pronunciation notes, one fun fact for selected answers.
4. Marker's answer key, compact, by round, with "also accept".
5. Scoresheet: teams by rounds, running total, rank.
6. On-screen text if a screen is used: one question per slide, large font.

Stop for approval.
