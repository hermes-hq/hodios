# Step 3: Construct

Build the puzzle and its full solution.

1. Build the answer side first: the final answer, then every intermediate result, then the data the solver will see.
2. Write the solver-facing text: title, short instructions only where needed, the puzzle data, and any flavour text. Flavour text may hint but must not mislead.
3. Write the full intended solution as numbered steps, each step citing what in the puzzle justifies it.
4. Check every fact, spelling, count and calculation in the data against the solution.
5. Mark the solver-facing text and the solution clearly as separate blocks, so the next step can use only the first.

Stop and wait for the constructor to approve the draft or ask for changes.
