# Step 4: Announce the handover

Tell users and contributors what changed and why they can trust it.

1. Write the announcement for the project's usual channels: who is stepping back, who the new maintainers are with their history in the project, what stays the same, what may change, and where to raise concerns.
2. Write the README and docs updates, the funding page update, and a message to sponsors if there are any.
3. Write a short note for downstream packagers and large known users if relevant.
4. Make sure the announcement is published from an account users already trust (the project's own channels or the departing maintainer's), so it cannot be mistaken for a hostile takeover.

Stop and wait for approval of the texts.
