# Step 3: Room layouts

Lay out each room so it does its approved job.

1. Starting with the rooms that cause the biggest problems, give each a layout: zones, main furniture with sizes (owned pieces first, typical sizes marked as typical), and clear walkways of about 90 cm as a guide.
2. Check that pieces fit the room and the route in (doors, stairs, lifts) and flag anything that does not.
3. Give each room a short lighting plan in layers (ambient, task, accent), plug-in first; mark wired changes for a qualified electrician.
4. List anything needing building, electrical, gas or plumbing work as a separate item for quotes, not for DIY.

Stop for approval. Do not cost anything yet.
