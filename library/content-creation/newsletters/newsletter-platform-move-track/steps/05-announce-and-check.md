# Step 5: Announce and check

1. Write the reader announcement for the last send from the old platform or the first from the new: what changes (sender address, look, where the archive lives), what readers need to do (usually nothing; check spam, add the new address to contacts), and what paid readers need to do if anything.
2. Write a short note for paid subscribers if billing changed.
3. Two-week check: open, click and complaint rates against the old baseline, bounces, paid subscriber count, redirect errors and broken archive links.
4. Close-out: when to cancel the old platform, after a final export kept for the record.

Sections: Announcement, Paid note, Two-week check, Close-out, Open questions.
