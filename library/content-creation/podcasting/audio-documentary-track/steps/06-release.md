# Step 6: Release notes

1. Title options and a two-sentence description from the final piece.
2. Show notes: credits (reporters, editor, music with licence), sources, content note, and support wording pointing to local emergency services or a crisis line in the listener's country where relevant.
3. A message to contributors with the release date, before it goes out.
4. Transcript plan for accessibility.
5. Corrections policy: how listeners report errors and how fixes are noted.

Sections: Titles and description, Show notes, Contributor message, Transcript, Corrections.
