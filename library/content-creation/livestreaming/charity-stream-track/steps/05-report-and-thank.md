# Step 5: Report and thank

1. Final total, from the fundraising platform's own figure, with any fees shown and when the charity receives it. If the user has not given the figure, ask for it and do not estimate.
2. Thank-you post for viewers and donors, and a thank-you note to the charity.
3. Incentives still owed: a list with dates, so promises made on stream are kept.
4. Short debrief: what worked, what to change, and whether to make it a yearly event.

Sections: Final total, Thank-you post, Note to the charity, Promises to keep, Debrief, Open questions.
