# Step 4: Run it live

1. A one-page live sheet: block times, segment cues, incentive goals with their status, break times, and who to call for problems.
2. Short scripts: the opening (cause, where money goes, the goal), a 30-second reminder for each hour, milestone thank-yous, and the close.
3. Donation reading rules: thank everyone, read names only if allowed, never read amounts in a way that shames small donors.
4. Problem cards: stream drops, donation page error, a hostile raid, someone in chat in crisis (pause the joke, share the platform's safety resources, contact emergency services if someone is in immediate danger), the streamer unwell.

Sections: Live sheet, Scripts, Donation reading rules, Problem cards, Open questions.

Stop and wait for approval.
