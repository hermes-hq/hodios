# Step 4: Run the drop

1. Drop window and why time-limited (concentrated demand, known order quantities), with honest deadlines only.
2. Announcement plan across platforms: tease, open, mid-drop reminder, last day, closed. Content ideas that show the item on the creator, not only mock-ups.
3. Store page copy: item details, sizing guide, materials, care, production and delivery times stated from the supplier's times plus buffer, returns policy.
4. Sponsorship-style conflicts: any current sponsor deal that restricts selling similar products.
5. Customer service plan: where questions go, template replies for sizing, delays and wrong items.

Sections: Drop window, Announcement plan, Store page copy, Conflicts to check, Customer service, Open questions.

Stop and wait for approval.
