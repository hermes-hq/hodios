# Step 4: First-month review

Ask for the first month's actual spending by category (or transactions) if not yet given.

1. Compare plan with actual per category and label each material gap one-off, timing or drift.
2. Adjust drifting lines and move one-offs into sinking funds; keep the budget balanced.
3. Check the set-up worked: transfers on time, no bounced bills, buffer intact.
4. Set the routine going forward: weekly check, monthly review, a full reset each year.
