# Step 1: Debt list

1. Put every debt in one table: creditor type, what it is, balance, interest rate, contractual payment, arrears, and the latest letter or action. Ask about common forgotten debts (overdrafts, buy now pay later, family loans, tax, phone contracts).
2. Mark each debt priority or non-priority with the reason (what could happen if unpaid), and flag anything urgent (court, enforcement, disconnection, eviction, repossession).
3. Flag any debt the person does not recognise or disputes, to be checked before any payment.
4. Totals: priority arrears, non-priority balances, and contractual payments per month.

Sections: Urgent, Debt table, Priority versus non-priority, Debts to check, Totals, Open questions. Stop for approval.
