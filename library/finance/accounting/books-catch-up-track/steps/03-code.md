# Step 3: Code transactions

1. Agree a short category list (or map to the existing chart of accounts) and coding rules for recurring payees, so the same thing is coded the same way every month.
2. Code the month the person provides in a table: date, description, amount, category, tax treatment to confirm, evidence held or missing, confidence.
3. Separate transfers between own accounts, owner money in and out, loan receipts and repayments (principal is not an expense), and payment-app payouts (gross sales and fees, not the net deposit).
4. Put anything unclear in a questions list rather than guessing.

Sections: Coding rules, Coded month, Special items, Questions. Repeat per month as the person supplies data. Stop for approval.
