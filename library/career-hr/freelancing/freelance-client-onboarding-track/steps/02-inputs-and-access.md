# Step 2: Inputs and access

1. List every input the project needs from the client (content, brand assets, data, examples, logins, decisions) with a due date and an owner on their side.
2. Mark which inputs block which deliverables, and state how a late input moves the timeline.
3. Write the request message: grouped list, one link or folder to upload to, due dates, and who to contact with questions.
4. Access plan: which accounts the freelancer needs, the least access that works, how credentials will be shared safely (never in plain email or chat), and when access will be removed.

Sections: Inputs table, Dependencies, Request message, Access plan. Stop and wait for approval.
