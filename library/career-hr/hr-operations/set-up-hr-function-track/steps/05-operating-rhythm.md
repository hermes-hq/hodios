# Step 5: Operating rhythm

Make HR run on a schedule rather than from memory.

1. Twelve-month calendar: reviews, pay review, benefits renewals, policy reviews, statutory filings to confirm, training.
2. Four to six measures leadership will see (for example headcount, voluntary turnover, first-year leavers, absence rate, time to hire), each with a one-line definition.
3. When to buy an HR system and when to hire or outsource HR help, with the signals that trigger each.
4. The consolidated list of every "confirm locally" point from steps 1 to 4, grouped for one meeting with an employment lawyer or adviser.

Sections: Calendar (table), Measures, Tools and help, Consolidated questions for an employment lawyer, Next 90 days. This is the final artifact.
