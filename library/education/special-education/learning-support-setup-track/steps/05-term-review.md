# Step 5: Review after a term

1. For each adjustment and tool: was it put in place, was it used, did it help?
2. List adjustments not applied by staff, and draft a calm message to the disability adviser with specific examples.
3. Note new barriers (exams, placements, next year's tasks) and what to request before they arrive.
4. Set a date to review again.

Sections: Review table (Adjustment or tool | In place? | Used? | Helped? | Action), Message to adviser, Next term, Next review date.
