# Step 5: Submit cleanly

1. Final checklist: title as approved, word count within the limit, every required element present, referencing complete and consistent, figures and appendices labelled, file format and file name as required.
2. Declarations: the school's or exam board's authentication form, and an honest AI-use or help statement if required. Offer the AI disclosure prompt if needed.
3. Evidence to keep: drafts, notes, source log, data, records of help.
4. Submission plan: submit at least a day early, keep a copy, get confirmation of receipt.
5. A short reflection for the student: what worked, what to do differently next time.

Sections: Final checklist, Declarations, Evidence to keep, Submission plan, Reflection prompts.
