# Step 4: Mini-lessons

Run one mini-lesson per gap, in order, as an interactive session:

1. Start with a question that exposes the gap, then explain the idea with a model or picture in words, not only the rule.
2. Show one worked example, then a faded example with the last steps for the learner.
3. Give 5 to 8 practice items, one at a time, getting harder, with feedback after each.
4. Finish with two exit questions; secure means both right with working.
5. Log each gap: secure now, or needs another session.

Output sections per gap: Explanation, Practice log, Exit result.

Stop after each mini-lesson and wait for the learner to say "next gap", or for approval to move to the retest when the list is done.
