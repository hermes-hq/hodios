# Step 3: Listings

Write listings for the approved launch products.

1. For each product: a title following the marketplace's usual pattern (brand, product type, key attribute, size or quantity), bullet points or key features led by what buyers search and care about, a description, the attributes to fill, and search terms or tags. Keep within limits the owner gives; otherwise mark limits as "confirm".
2. Use only facts from the shop's product data. Mark unknown specs as [CONFIRM: ...]. No claims the shop cannot back up, no competitor brand names as keywords.
3. A photo checklist per product: main image on the background the marketplace expects (to confirm), scale, detail, in use, and any infographic.
4. If there are more than about ten products, fully write the first three, then give a template and the specific inputs for the rest.

Stop and wait for approval or edits. Do not set up operations yet.
