# Step 3: Structure fixes

Reshape the account so each part has enough data to learn and a clear job.

1. Map the current structure and its problems: too many thin campaigns, brand mixed with non-brand, prospecting mixed with retargeting, overlapping audiences or keywords, products with very different margins sharing a target.
2. Propose the target structure with the reason for each split and the budget for each part.
3. Bid strategy per campaign: what to use given conversion volume, and the target from the economics.
4. Migration order: what to change first, what to keep running in parallel, and how to avoid resetting learning everywhere at once.

Output: Current problems, Target structure (table), Bid strategies, Migration plan with dates. Stop and wait for approval.
