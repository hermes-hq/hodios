# Step 5: Link the cluster and set up measurement

1. Linking map: pillar to every supporting page, each supporting page back to the pillar and to the commercial page, and sideways links only where readers need them. Add links from existing high-traffic pages into the cluster.
2. Publishing checklist: indexable, in the sitemap, unique title and description, links live, structured data only where it matches visible content.
3. Measurement at 30 and 60 days after each page goes live: indexing, impressions and average position for each main query, clicks, and assisted enquiries or sales from the cluster. Name the report where each is found.
4. Decision rules at 60 days: expand pages gaining impressions, rework pages indexed but with no impressions, and only then plan the next batch.
