# Step 4: Updates to resolution

Keep the promised rhythm until the matter is resolved.

1. Update the facts board with the new confirmed facts. Call out anything said earlier that is now wrong and draft the correction first.
2. Draft the next update for each audience, at the committed time, saying what is new, what is still unknown and when the next update will come.
3. When the cause and responsibility are established, decide with the user whether a full statement or an apology is needed, and draft it: specific acknowledgement, ownership without conditional phrasing, impact, remedy and changes with dates, from the accountable leader.
4. Define what "resolved" means for communications (affected people helped, cause explained, changes committed) and draft the closing update.
5. Plan when to resume normal marketing and how to handle the anniversary or follow-up coverage.

Stop and wait for approval. Repeat this step for each update cycle if the user asks.
