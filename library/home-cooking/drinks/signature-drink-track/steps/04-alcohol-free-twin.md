# Step 4: Alcohol-free twin

Build an alcohol-free version as good as the original, not juice in the same glass.

1. List what the alcohol was doing in the drink (body, warmth, bitterness, aroma, dryness) and how to replace each: tea, verjus, shrubs, bitter or spiced syrups, saline, tonic, or alcohol-free spirits if the user wants them.
2. Write the twin recipe in ml with method, glass and a garnish that matches the original so it feels part of the same menu.
3. Note that some alcohol-free spirits, bitters and kombucha can contain traces of alcohol, and offer a fully 0.0 option for anyone who must avoid alcohol completely.
4. Give a tasting plan as in step 2, then adjust from the user's notes one change at a time.

Stop for approval of the twin.
