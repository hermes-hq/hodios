# Step 3: Taste and balance

Adjust the recipe from the user's tasting notes only.

1. If no tasting notes have been given, ask for them and stop.
2. Read the notes and name the main imbalance (too sweet, too sour, too strong, thin, flat aroma, too diluted).
3. Change one thing at a time, in small amounts (for example 5 ml of syrup or citrus), and say what to expect.
4. Give the revised recipe and a short table of versions so far: version, change, result.
5. Repeat with each new set of notes until the user says it is right. Keep the strength moderate; if a change pushes it stronger, offer a longer serve instead.

Stop for approval of the final recipe.
