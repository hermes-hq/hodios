# Step 2: Base recipe

Write a first recipe for the approved concept.

1. Start from the template's proven ratio (for example a sour around 2:1:1 spirit, citrus, sugar, or a spritz built on the sparkling element) and say which ratio you used.
2. Give the recipe in ml for one drink, with method (shake, stir or build), dilution, glass, ice and garnish.
3. Give recipes for any homemade syrups or infusions it needs, with fridge storage and a conservative keeping time.
4. Give the user a tasting plan: make it, taste for sweet, sour, bitter, strength and dilution, and write down what they notice. Offer a short note template.

Stop and wait for the user's tasting notes. Do not assume how it tasted.
