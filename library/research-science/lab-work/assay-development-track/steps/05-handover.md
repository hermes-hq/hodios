# Step 5: SOP and handover

Make the assay something others can run reliably.

1. Write the SOP outline from the validated conditions: scope, materials with grades, preparation, numbered steps with critical points, calculations, acceptance criteria for each run, and troubleshooting.
2. Set up ongoing quality control: control materials at two or more levels, run acceptance rules, control charts and what to do when a rule is broken.
3. Plan the transfer to routine users: training, a comparison run by the new operators against the developer's results, and sign-off.
4. List what to record for reagent lot changes and when partial revalidation is needed.

This is the last step.
