# Step 2: Source requests

1. For each logged claim, record what the author has already supplied (notes, recordings, documents, endnotes) and what is missing.
2. Draft one consolidated request to the author: per claim, the source needed (recording or notes for quotes, the document for a figure, contact details for people to re-interview), grouped by chapter, with a reply date.
3. List the independent sources the checker will use without the author: official records, original studies, archives, and people to contact for confirmation.
4. Note any source that the author says is confidential and how it will be checked without exposing it (for example the editor reviewing the notes directly).

Write sections: Source status (table), Request to author, Independent sources, Confidential sources. Stop and wait for approval.
