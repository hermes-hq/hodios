# Step 5: Final pass

1. Check tone: remove sarcasm, remarks about the authors, comments on presumed language background, and hedging that hides essential requests.
2. Check consistency: the recommendation matches the major issues; nothing in the confidential comments contradicts the report; no request to cite the reviewer's own work without a specific need.
3. Check that every issue has a location or a "[location]" placeholder for the reviewer to fill.
4. Give the final report, ready to paste into the submission system, and a short checklist: policy checked, conflicts declared, confidential copies deleted after submission.

Write sections: Changes made, Final report, Submission checklist.
