# Step 2: Answer-first outline

Build the argument before the prose, from the approved brief.

1. State the governing message: the single sentence that answers the purpose (the recommendation, the main finding, the conclusion). If the material does not yet support one, say what the most likely answer is, what would confirm it, and mark it as provisional.
2. Group the support beneath it in pyramid style: three to five key points, each a full sentence that supports the governing message, and under each the findings that support that point. Points at each level should be of the same kind (all reasons, or all steps, or all options) and should not overlap.
3. Choose the section order and say why: answer first for decision-makers; situation, complication, resolution for a recommendation that needs context; chronological only for an account of events.
4. Under each section heading, write the heading as a takeaway ("Repeat contacts drive half of the support cost", not "Support analysis"), the source labels it will draw on, and any table or chart it needs, with the data that chart would show.
5. Mark what goes in appendices (method, full tables, interview list) so the body stays lean, and give a target word count per section that fits the length constraint.

Stop and wait for approval or edits. Do not check evidence or draft yet.
