# Step 2: Paragraphs

Apply the approved outline, then edit at paragraph level.

1. Show the restructured document, marking moved, merged and new sections. Where new content is needed, insert [WRITER TO ADD: what is needed] instead of inventing it.
2. Check that each paragraph has one job and a first sentence that says what it is.
3. Fix transitions between paragraphs and sections so the reader always knows why the next part follows.
4. Split overloaded paragraphs; merge fragments that make one point.
5. List each change in a short table: location, change, reason.

Stop for approval before line editing.
