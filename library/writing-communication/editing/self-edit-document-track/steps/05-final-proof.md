# Step 5: Final proof

1. Proofread the final text for typos, doubled or missing words, agreement, punctuation and apostrophes, without restyling.
2. Check headings, list numbering and any placeholder text left behind ([WRITER TO ADD], TK, XX, comments).
3. Output the clean final text, a table of proof corrections, and a short release checklist of what only the writer can check (facts, links, names, approvals, layout).
