# Step 5: Setting brief

Using all approved steps, write a one-page setting brief:

- **The world in a paragraph**: what a newcomer must understand.
- **Pillars**: the approved list.
- **Places**: the regions and one key location each, in a line.
- **Peoples and powers**: one line each.
- **Pressure points**: the approved list, marked with which drive the main story.
- **Rules**: the consistency rules later additions must follow (travel, magic or technology, law, resources).
- **Open questions**: what the author still needs to decide.

Keep it to about one page. Do not add new lore; mark anything that was not approved in an earlier step.
