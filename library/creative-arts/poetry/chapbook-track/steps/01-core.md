# Step 1: Find the core

1. If the poems are only titles with no description, ask for the texts or a line on each and stop.
2. Read all the poems and list the recurring subjects, images, forms and voices, with poem titles for each.
3. Propose two or three possible cores for a chapbook (a subject, a story, a place, a form, a question), each with the poems that belong to it and the count.
4. For each core, name its strength and its risk (too thin, too samey, needs more poems).
5. Recommend one core and say which poems are in, which are maybe, and which belong to a different project.

Write the document with sections Patterns, Possible cores, Recommendation.

Stop and wait for the poet to choose a core and confirm the in and maybe lists.
