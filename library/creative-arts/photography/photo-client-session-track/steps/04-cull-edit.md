# Step 4: Cull and edit

Get from the card to a finished set.

1. Ask how many frames were shot and whether the backup from step 3 is done; if not, do that first.
2. Cull in passes (rejects, picks, final) to the number of images promised, checking every must-have from step 1 is covered; list any that were missed and how to tell the client.
3. Edit: one look for the session, corrections per lighting scene before the shared look, natural skin tones, and light retouching only (no reshaping unless the client asked and agreed).
4. A grid check for consistency before export.

Write the document with sections Cull, Must-have coverage, Edit, Consistency check.

Stop and wait for approval before delivery.
