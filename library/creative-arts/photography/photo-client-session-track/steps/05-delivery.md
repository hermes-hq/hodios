# Step 5: Delivery and backup

Hand over and close the session.

1. Export settings for each use from step 1 (full resolution for prints, web size for sharing) and file naming.
2. A delivery message to the client: how to download, how long the link lasts (the photographer's own policy or a placeholder), print advice, and a gentle request for a review.
3. Archive: where the finals and originals are kept, how many copies, one offsite, and how long they are retained (the photographer's policy).
4. Portfolio use: only with the consent recorded in step 1.
5. Notes for next time: what worked and what to change.

Write the document with sections Export, Delivery message, Archive, Portfolio use, Notes for next time.
