# Step 5: Draft and rewrite plan

Plan how the writer gets from approved pages to a draft worth sending out.

1. Set a drafting schedule from the writer's available time: pages per session, milestones at the act breaks, and a rule to keep drafting forward and log fixes rather than rewriting mid-draft.
2. List the open questions from steps 1 to 4 that the draft must answer, and where in the outline each lands.
3. Plan the rewrite in passes (structure, character, scenes, polish) with what each pass checks.
4. Plan feedback: when to get reads, from whom (peers, a table read), and what to ask them; then how to sort notes before changing anything.

Write the document with sections Schedule, Open questions, Rewrite passes, Feedback plan.
